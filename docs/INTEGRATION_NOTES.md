# Integration notes

Append-only. One bullet per note, prefixed with your area, e.g. `- [sim] Added sim.foo() because ...`.

- [units] `src/data/units.js` is complete (19 units). Extra helpers beyond §3: `UNIT_IDS`, `unitsByRarity(r, {kind})`, `freeUnlocksByStage()` (`{'1-2':['yuki'],'1-5':['nami','sango'],...}`), `hasCapability(unit, cap, {includePaths})`, `unitsWithCapability(cap, {includePaths, kind})`, `tierCost(unit, path, tier)`, `pathCostTo(unit, path, tier)`. `getUnit` throws on unknown ids (per contract).
- [units] For sim: tier mods are incremental (tier N applies tiers 1..N). `base` always carries numeric `silence`/`reveal`/`knockback` (0 default). Optional objects (`aura`, `income`, `trap`, `turret`, `ramp`, `mark`) exist only on units that start with them; upgrades may INTRODUCE `aura` (always with `range`), `ramp` (per+max) and `mark` (bonus+duration) — please create the object on first merge (e.g. `max(undefined, x)` must not become NaN). `trap`/`turret`/`income` mods only appear on units whose base already has that object.
- [units] For sim: element effects are explicit in `base.status` (Akane burn, Yuki/Nami slow, Raika shock, Midori poison, Sango/Umeko soak) — no need to auto-add element statuses. Status lists may contain `silence`/`reveal` StatusSpecs inside `trap.status` (Suzu seals) in addition to the numeric `silence`/`reveal` on-hit keys.
- [units] For sim: transformations at tier 4-5 — Hikari p3t4 `behavior:'projectile'` (pulse→lances; also sets projectileSpeed via add from 0), Rei p2t4 `behavior:'duel'` (+ramp introduced), Yuki p1t5 `behavior:'pulse'`, Raika p2t4 `behavior:'beam'`, Miko p2t5 `behavior:'beam'`, Chika p3t4 `behavior:'chain'` + `attackType:'mystic'` + `rateMul: 4` (her base rate 0.25 is the drone build rate), Suzu p3t4 `attackType:'holy'` (applies to her traps).
- [units] For sim: hero `levelXp[i]` = XP to go from level i+1 to i+2 (per-level increments, not cumulative). `hero.levels` has entries for levels 1..10 (level 1 mods are `{}`); apply each level's mods once when reached. Heroes also have 3 upgrade paths like towers (schema requires them).
- [units] For systems/meta: `acquisition.note` holds a player-facing sentence for free recruits; `unitsWithCapability(cap)` returns base owners first, useful for `recommendedFor`.
- [sim] `src/sim/**` is complete: `import { Sim, runHeadless, autoPlan } from './sim/index.js'` (or `./sim/Sim.js` / `./sim/headless.js`). Default data is loaded via `import.meta.glob` (works in Vite + Vitest, not in plain `node`); missing data files yield empty tables, so pass `data` overrides in tests.
- [sim] Extra Sim API beyond §6 (all optional to use): `placeCost(unitId, tx?, ty?)` (tower-bar prices; pass a tile to include cost-cut auras), `getTower(uid)`, `tileAt(tx,ty)`, `pathTiles` (Set "x,y"), `pathData` (polylines with `cum`/`length`), `spawnEnemy(id,{pathIndex,dist,hpMul})`, `endless`, `wavesCleared`, `waveWarnings(n?)`, `debrief()`, `addGlobalRateBuff(mul,sec)`, `globalRateMul`. `sim.paths` = array of `[[x,y],...]` world polylines (tile centres).
- [sim] For renderer: every `facing` (EnemyRT, TowerRT, turret) is `atan2(dx, dy)` radians → use directly as three.js `rotation.y` (models face +z; sim y = world z). Enemy `alt` = 1.2 when airborne. ProjectileRT `z` is the flight height (shells/fireballs/flasks arc). Traps carry `armed`. Fields are rebuilt each step: key by `uid` (= the caster enemy uid).
- [sim] Events beyond §6: `blinkInterrupted {uid}` (remove the teleport marker), `attack.kind` is the projectile kind or `pulse|slash|beam|chain|trap|build|bullet` (`build` = drone built, `bullet` from a drone has `turretUid`), `attack.ramp` on duel slashes, `explode.volatile=true` for enemy death blasts, `spawn` carries `pathIndex,x,y,parentUid`, `place` carries `unitId,tx,ty`, `heroLevel`/`ult` carry `towerUid`, `cash.reason` is `waveBonus|income` (kill bounties are in `death.bounty`). `hit.amount` includes barrier damage.
- [sim] For battle-ui: `sim.waveWarnings()` → `[{kind:'boss'|'new'|'counter', severity:'danger'|'warn'|'info', text, enemyId|enemyIds, trait, capabilities, suggest:unitIds}]` (e.g. "Veiled enemies incoming (Veil Wraith ×6) — bring Veil Sight or Reveal. Kage can help."). `sim.debrief()` → `{ lines: string[], leaks: {enemies, waves, traits}, damage: [{uid,unitId,name,damage,share}], livesLost }` (e.g. "Most leaks were Goblin Runner on wave 12 (14 lives)."). Both reuse UnitDef.capabilities/pathCapabilities for suggestions.
- [sim] For systems (`applyBattleResult`): `result()` = `{ stageId, difficulty, won, wave, wavesCleared, livesLeft, maxLives, encountered, kills, stats }`; `stats.leaks` = lives lost, `stats.enemiesLeaked` = count, plus `leakLog [{wave,enemyId,lives,time}]`, `leaksByEnemy`, `leaksByWave`, `damageByTower`, `damageByType`, `towerUnits {uid: unitId}`, `cashEarned`, `time`, `heroLevel`. Use `wavesCleared` as the challenge best wave.
- [sim] For systems (`unitBattleStats`): sim reads `damageMul/rateMul/rangeMul` as multipliers, `critChance` and `armorPen` as additive, `critMul` as a MULTIPLIER on the unit's crit damage multiplier (1 = unchanged, 1.12 = +12% crit dmg), `costMul` on placement + upgrade costs, `ultHaste` as a cooldown fraction (capped 50%), `awakenPassive: true` applies `UnitDef.awakenPassive.mods`. Missing keys default to neutral.
- [sim] For world (enemy semantics): `field.amount` = haste speed bonus / shield damage-reduction fraction / regen fraction of max HP per s (strongest field wins, includes the caster); optional rotation `field: { kinds: ['haste','shield','regen'], every, radius, amount }` for the Oni Champion. `siphon.rate` = HP/s from EACH neighbour (scaled by the enemy's HP multiplier). `enrage.max` ≤ 1 = max bonus fraction, > 1 = max speed multiplier; packmates = same family within 6 tiles. `regen.pct` per s after `delay` s without damage. `barrier.hp` scales like HP; `crystal.cap` does not. `guardian` does not protect itself. Phases: `set.traits` merges (null/false removes a trait), `set.speed` is pre-difficulty. Missing `leak` defaults: normal 1, elite 5, miniboss 25; bosses always take all lives.
- [sim] For world (wave generation): groups are ordered slowest-first and overlap (fast enemies catch up with tanks — the "orcs escorting oni, goblins slipping through" pattern); pool entries whose `threat` exceeds 60% of that wave's budget are skipped (put minibosses/bosses in `fixed`); number of mixed groups grows 1 → `groups` every 3 waves; elites ramp in over ~4 waves after `from`; on top of `hpScale` the sim adds +1.5% HP per wave; spawns per wave are capped at 140 (excess budget → HP); `fixed[].delay` defaults to 2 s. Waves are deterministic per stage id + wave (seed-independent).
- [sim] Heroes: their 3 upgrade paths are purchasable in battle (same crosspath rules) on top of levels; XP = 1 per damage dealt + (30 + 10×wave) per cleared wave; the ult starts at 50% charge when unlocked and only charges during waves. `timeWarp.rateBuff` > 1 is a multiplier, ≤ 1 a bonus fraction.
- [sim] Resistances: bosses take 25% freeze/stun/shock duration and 50% slow strength (minibosses 50% / 75%); knockback/pushback: bosses immune, minibosses half. Holy hits cancel phasing and silence field casters for 2 s. A tower with a cleanse aura (and every tower inside it) ignores sabotage and volatile stuns.
