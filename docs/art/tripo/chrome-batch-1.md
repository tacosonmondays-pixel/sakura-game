# Tripo website hand-off, batch 1 (for Claude in Chrome)

The owner generates these on the Tripo **website** (web credits) and uploads the downloads to the session; we process
them (decimate, rig or retarget, previews, import) like `docs/art/tripo/batch-1.md`. The API credits are kept for
later. 54 rows: **P1 first** (the one batch-1 model that was rejected, then the 14 gear looks the new gear slots lack),
then **P2** (the heroes, Seiran's sky dragon, the bosses and titans, one model per enemy family, the story landmarks).
Prompts are copied verbatim from `docs/art/ASSET_WISHLIST.md` (branch `docs/asset-wishlist`); the gear prompts use its
gear pattern. Reference pictures are the game's own art, in `docs/art/tripo/refs/`.

## Instructions for Claude in Chrome

1. Open https://www.tripo3d.ai and sign in as the owner (they log in themselves; never type a password).
2. Work down the table one row at a time, starting from the first unchecked row. **Stop after the number of rows the
   owner asked for** (default: 10), then report which rows are done.
3. For each row: open the generator named in **mode** (Text to 3D, or Image to 3D with the reference file), paste the
   **prompt** exactly, paste the **negative prompt** below if the page has a field for it, then set the options:
   * texture **on**, texture size / quality **standard (1024)**, PBR off;
   * style: none / original (no stylisation preset);
   * face limit (or polycount / "low poly" target) = the row's **faces**;
   * pose: the row's **pose** (A-pose for figures, if the page offers T/A-pose; otherwise leave it);
   * then generate.
4. **Review** the result before downloading, in the page's 3D viewer, turning it around:
   * it is ONE object, in one piece, standing upright, no base or ground plate, no text;
   * figures are chibi (big head, short body) and **fully, modestly dressed**: no swimsuits, no bare midriff, no
     short skirts, nothing revealing, never framed around the body; adults in professional clothes; no gore anywhere;
   * if it is broken (pieces floating, flat, merged into a blob) or not what the prompt says: **retry once**, then
     move on and mark the row "retry failed".
   * If anything looks revealing, do not download it; mark the row "rejected: content" and move on.
5. If **rig** says ON and the result is a two-legged figure, run the site's auto-rig (humanoid / biped). Download the
   rigged model too.
6. **Download as GLB** and save it with the row's **file name** exactly (the rigged one with `_rig` before `.glb`).
7. Tick the row in your checklist (row number, file name, done / retried / rejected and why). Upload the GLBs and the
   checklist to the session, or tell the owner where they are.
8. Never upload anything but these prompts and the files in `docs/art/tripo/refs/` (the game's own art). Never type the
   name of another game, show or artist into a prompt.

**Negative prompt (every row):** `realistic proportions, long legs, revealing clothes, swimsuit, short skirt, cleavage, bare midriff, gore, blood, text, logo, base, pedestal, ground plane, multiple characters, extra limbs`
