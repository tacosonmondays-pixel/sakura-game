## Chibi style: `chibi-style-hikari-turnaround.webp` (approved 2026-10-07)
The owner on seeing it: "WAIT IS THAT THE CHIBI??" / "THATS LITERALLY PERFECT".

This is **the** chibi look for every girl, both the 3D battle chibis and any 2D chibi art.
- About 2.5–3 heads tall, very large round head, small soft body, short limbs, small hands and feet.
- Huge shiny anime eyes with thick dark upper lashes, bright highlights and gradient irises; light blush; small smile.
- Blunt bangs with sharp pointed strands; long hair and ribbon detail kept from the character's full illustration.
- Flat two-tone cel shading, thin dark outlines, clean readable shapes, many small costume details, like a Blue Archive SD chibi.
- Modest, fully covering outfits taken exactly from the character's full illustration.

How it was made: Meshy image-to-image (`nano-banana-pro`, `generate_multi_view: true`). The reference was the character's full illustration (`hikari.webp` from the Codex build), plus a crop of the old Codex chibi as a proportion guide. The exact prompt is in `chibi-style-hikari-prompt.txt`; reuse it per character, changing only the design description. Each run costs 9 credits.
