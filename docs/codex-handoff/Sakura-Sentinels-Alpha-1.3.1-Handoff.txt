   access appear gradually. The campaign grew to 22 distinct maps, including

   Server reward verification replays battle actions and rejects forged clears,
   invalid placements/cash, out-of-order claims and duplicate payouts.
   PWA manifest/icons, installation guidance, update activation and save recovery
   are included. This remains a browser-rendered game.

5. Reset and Safari recovery fixes
   reset 67 resets only the redeeming collection, returns to the main menu and
   restarts the tutorial. It resets recruits, growth, inventory, currency and
   stage records, invalidates old runs and preserves the save identity. Device
   graphics/audio settings remain separate. Retrying the same reset receipt
   cannot erase progress earned later.
   /api/browser-repair refreshes game caches without clearing save identity.
   Service-worker rules prevent redirected sign-in/navigation responses from
   poisoning Safari's offline cache. Historical publishing connection failures
   were resolved in the earlier conversation; the recovered source includes
   both the reset and recovery changes.

6. Alpha 1.3 progression, deployment and summer event
   Animated ENTRY/EXIT indicators follow actual routes, including reversed and
   alternating lanes. Dragging cards or a selected defender onto valid terrain
   deploys exactly once; camera drags, canceled gestures, pinch and off-board
   releases do not place. City residents follow the unlocked collection.
   A free Academy ten-pull after 3 distinct campaign clears introduces upgrading.
   Replayable Captain's Journal lessons teach the growing collection systems.
   Resource access starts after 5 chapters; equipment and the event after 6;
   sandbox after 7; bosses at 8/14/20; awakening after 10. Resource families and
   higher tiers have their own chapter milestones. See feature-progress.js.
   Login gifts form a repeating seven-step track, claimed once per Chicago
   7 PM cycle. Missing days does not reset the track.

   The Beach Day That Got Away has 10 original story chapters, five operations,
   a temporary event currency/shop, equipment, gifts, affection conversations,
   and permanent Marina/Amane/Nami beach outfits. Marina comes from story 1.
   Seaglass Leviathan is a 12-wave expert encounter requiring 20 campaign clears
   and event completion; its first clear recruits Amane and grants major loot.
   Server transactions validate story order, energy, purchases, gifts and rewards.
   Event characters are separate from ordinary recruitment pools.
   The source sets an event start of 2026-10-03T05:00:00Z, end of
   2026-11-03T01:00:00Z, and shop end of 2026-11-10T01:00:00Z. These are finite
   dates, not a permanently active event; the desktop snapshot preserves them.

   A reproducible developed F2P strategy clears the expert encounter at level
   28, awakening 1, one copy per girl, craftable Rare tier-2 gear, with 45/75
   hearts. Its level-20 version fails on wave 4. This proves an automated clear,
   not a player-percentile win rate. Source and strategy records are included.

GRAPHICS, MODELS AND SOUND

The runtime is vanilla HTML/CSS/JavaScript with bundled Three.js r180, Draco
decoding, Lucide, fonts and licenses. Procedural scene geometry provides city,
enemies, weapons, scenery, routes, battle effects and hero sequences. Mesh
characters are GLBs under source/dist/assets/models/; rigs and meshes are real.
The game-ready files use Draco compression. models-uncompressed/ contains
decoded copies for authoring, with exact geometry/weight comparisons recorded.
The face atlas is assigned/switched by the runtime. Character acting is code
in chibi-acting.js and related modules; it is not exported animation clips.
No authored .blend project was recovered. Blender Python construction/refinement
scripts and the supplied base GLB are included to reproduce/edit the pipeline.

Lighting/post processing includes bloom, grading, fog, tone mapping and quality
settings. Actual-device iPhone frame rates and Windows GPU appearance were not
measured during packaging. Existing offline image reviews are preserved as
offline evidence. They are not live device screenshots.

Music and effects currently come from Web Audio synthesis in source/dist/audio.js.
No completed V2 orchestral soundtrack or recorded WAV/MP3 album was recovered.
Preserve the audio source; the requested new soundtrack is part of future work.

WINDOWS LOCAL PLAY MODE ADDED IN THIS EXPORT

Run SakuraSentinels.exe after extracting the package. It launches a bundled
Windows Node runtime, adapts the unchanged Cloudflare Worker API to local SQLite,
and opens the game using Edge or Chrome's app window. A default browser is used
when those browsers are unavailable. The launcher control window must stay open
while playing; Stop and close shuts down the local service.
The game assets and local reward verification work without the hosted website.
This is a packaged web-rendered snapshot, not a Unity/Godot conversion.

Local server address: http://127.0.0.1:43187
Save and browser profile: %LOCALAPPDATA%\SakuraSentinels\DesktopAlpha1.3.1\
Database: collection.sqlite (plus SQLite WAL files while open)
Logs: server-output.log and server-errors.log
The launcher and local service use a private shutdown token. The service listens
only on loopback, validates Host/Origin and keeps files/API data scoped.
The local save starts fresh and is separate from the existing online collection.
This bundle does not import live player records or recovery keys. Locally owned
files are editable by the PC owner; the desktop save is not a tamper-proof cloud
economy. Local changes do not synchronize to production.
Published website updates do not automatically replace this desktop snapshot.
Use the online game for the latest deployment, or rebuild/export a new snapshot.

The outer EXE is a self-extracting archive. It asks for an output folder, checks
its embedded ZIP checksum, unpacks into a new directory and offers local play.
Existing folders are not overwritten. The matching ZIP contains the same files
and can be inspected/extracted without running the EXE.
The native launchers are unsigned x64 PE executables with an asInvoker manifest.
They use system Windows PowerShell to run the included, auditable scripts.
Windows 10/11 x64 is the target. Browser installation is not included.
The bundled official Node v22.16.0 executable was matched to its published
SHA-256. Its license and release checksums are included in runtime/.

DEVELOPMENT AND HANDOFF

Start by reading this guide, the catalog and the V2 roadmap. source/ is the full
editable project. Most first-party web modules live directly in source/dist/;
dist/client and dist/server are generated build output. Preserve .openai/hosting.json
when continuing the same hosted project. The database schema/migrations are
included; hosted D1 data and authentication/hosting secrets are not exported.

For normal source development, install an appropriate Node runtime and Git.
From source/: npm ci; npm test; npm run check; npm run build.
The included Windows node.exe alone does not include npm; obtain npm with the
developer's Node installation for source dependency installation/building.
Optional model reconstruction requires Blender plus the documented script tools.
Do not assume Blender material nodes will automatically reproduce in the runtime.
