## Follow-up roadmap chat (summary of the owner's V2 asks + recommendations they liked)

Owner asked for: Blue Archive–style UI overhaul (menus, transitions, animations); brand-new music
(orchestral to cute); audit that every earlier request was really implemented; global chat, transfer
codes, clans, and a dev clan joinable with the developer clan's private code (set by the owner in the database) whose bot grants materials in any quantity;
proper icons for every material; backpack organised by item category instead of rarity; Chibis v2
following the reference videos (third link = dinosaur-hoodie chibi modeling time-lapse is the main
target); Maps v2 as vibrant and alive as Bloons TD6 with better shaders/animation; harder difficulty
(Battle Cats / Bloons TD6 level — "far too easy"); Enemies v2 that are engaging and reward tactics but
are NOT convoluted.

Recommendations from that chat worth building (owner asked "any other mechanics?"):
- Quality bar: prove one excellent character (Hikari), one map and one menu→battle loop, then roll out.
- Enemy roles players understand instantly: Runner, Swarm, Armored, Support; one rule per ordinary enemy.
- Pre-wave warnings; evidence-based defeat debrief ("most leaks were runners on wave 12").
- Motion system: 80–120 ms press, 180–260 ms panels, 300–450 ms screens; designed empty/locked states.
- Upgrade requirements show icon + name + owned/required + where to obtain.
- Soundtrack built around one recurring melody in different arrangements (title, city, battle, boss, gacha, victory).
- Link Arts: role-based team combo attacks (controller+area, armor-break+precision, support+rapid).
- One commander tool chosen per mission (Rally, Overclock, Emergency Ward).
- Interactive battlefields (bridge switching routes, lantern reveal, clear debris for rooftop slots), previewed and predictable.
- Optional mission contracts (limited defenders, second entrance, reduced funds) for medals/cosmetics.
- Mastery trials per character unlocking skill variants; character trial stages before pulling.
- Living clubhouse/city hub where girls act out interactions; furniture unlocks interactions.
- Roguelite expeditions with run-only modifiers and temporary recruits.
- Equal-roster puzzle challenges with share codes; tactical lab sandbox with damage breakdowns; formation blueprints.
- Progression planner (pin goals, see missing materials and conflicts); sweep for mastered farm stages; fast restart.
- Dev clan (joined with the developer clan's private code (set by the owner in the database)) as a clearly marked developer sandbox; transfer codes treated like account access.
